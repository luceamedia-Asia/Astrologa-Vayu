# Astrologa Vayu – strona

Statyczna strona (HTML + CSS) dla Astrologa Vayu – astrología védica.

## Pliki
- `index.html` – treść strony (hiszpański)
- `styles.css` – wygląd i wersja na telefon
- `assets/` – grafiki (karta urodzeniowa, gwiazdy, fazy księżyca, zdjęcie, favicon)

## Przed publikacją
1. W `index.html` zamień `TU_ENLACE_DE_RESERVA` na prawdziwy link do kalendarza/rezerwacji.
2. Sekcja „Testimonios” zawiera przykładowe opinie – zastąp je prawdziwymi albo usuń sekcję.

## Publikacja
Projekt nie wymaga budowania – Vercel publikuje go jako stronę statyczną (Framework: Other, bez komendy build).
